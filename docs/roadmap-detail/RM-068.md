# RM-068 — OpenCode V2 post-merge optionals

> Detail file for roadmap row `RM-068`. Status and rank live in
> `docs/ROADMAP.md`; this file is provenance.

Source: the 2026-10-29 post-merge review of the OpenCode V2 cutover
([framework PR #132](https://github.com/hierovision/ai-framework/pull/132)).
Scope was the approved optional follow-ups only: loader proof (N1), the
heartbeat append race (F11), temp accumulation (F12), and the startup-latency
disposition. No global cutover, rollback, install, or real session-DB write
was performed.

## What changed

- **N1 — real loader proof.** The versioned config now wires
  `./plugins/auto-compact-at-threshold` (a bare `plugins/...` spec is an npm
  package spec in V2 and fails with `NpmInstallFailedError`). The plugin emits
  its startup marker to stderr because 2.1.4's plugin context has no log
  domain; post-smoke runs the real CLI (`--standalone --print-logs
  --log-level info`) and requires the loader's `loading plugin` line for the
  versioned directory plus the marker. The runtime probe remains required.
- **F11 — heartbeat append race.** The dispatcher no longer holds a buffered
  writer on the heartbeat file. `scripts/heartbeat_io.py` writes each record
  as one `O_APPEND` write; the observer uses the same helper. This removes the
  stale-offset overwrite that left a bare `unning` line in the D5 heartbeat.
- **F12 — bounded scratch.** Successful dispatches remove their generated
  config; failures keep it as evidence and the next dispatch prunes to the
  newest five / seven days. `.scratch/test-tmp` is pruned before test
  workdirs are created, and `test_model_policy` fixture repos are removed at
  process exit.
- **Startup latency.** The runner measures spawn → first stdout event and
  reports it in the opt-in startup log and in zero-event stall detail. The
  20-minute job ceiling and 600 s per-eval ceiling are unchanged; the dated
  measured residual is in `reference/opencode-integration.md`.

## Evidence

- Loader probe (2026-10-29, real 2.1.4 binary): the stderr log contains
  `msg="loading plugin" id=.../plugins/auto-compact-at-threshold` and
  `{"service":"auto-compact-at-threshold",...,"message":"auto-compact-at-threshold initialized"}`;
  `check_plugin` returns PASS with both the runtime and loader evidence.
- F11 regression test: three concurrent `SURVEY running` appends during a
  paced dispatch; every line matches a complete record (`START`/`DONE`/
  `SURVEY`) and no `unning` fragment remains.
- F12 regression tests: prune keeps the newest three, removes an older-than-
  seven-day entry, a failed dispatch leaves five bounded evidence dirs, a
  successful dispatch leaves only pre-existing dirs.
- Startup evidence: `.scratch/ci-132/*/run-2026-10-28.jsonl` (23.5 s, 53.2 s,
  57.9 s, 166.3 s, 406.7 s; three 60 s zero-event stalls).
