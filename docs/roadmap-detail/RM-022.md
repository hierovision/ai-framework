## Acceptance as delivered (verbatim)

A long dispatched subagent must be observable while it runs: bounded ≤10 min checkpoints, a mandatory timestamped heartbeat file (`.scratch/<program>/progress/<task>.log`) with `CALL begin/end` around any command >30 s, no blocking call over 180 s (eval rounds detach with a log and are polled), and explicit scope prohibitions (no `git` mutations, no global `~/.config/opencode` installs, no mutation outside the repo). The watchdog (`.scratch/skill-gap-analysis/tools/watch_agent.py`) cross-checks the heartbeat against opencode's own session event stream — opencode records no real tool durations, so liveness/thrash comes from inter-event quiet gaps — and flags STALLED / BLOCKING WAIT / LOOP / out-of-scope mutation, non-zero exit on a bad verdict. Acceptance: a dispatched subagent's progress is visible in the orchestrator's own turn (JSONL/heartbeat polls), a stalled or black-box run is flagged within one poll, and no global-state mutation survives a cancel; promote `watch_agent.py` into `scripts/` with tests. **Trigger**: fired — D2 incident 2026-09-28 (see `.opencode/plans/skill-gap-analysis-phase-d.md` History); #53 adds the implementer-loop incident. **Delivered 2026-10-01 ([PR #80](https://github.com/hierovision/ai-framework/pull/80)):** `scripts/watch_agent.py` (pure `verdict()`/`verdict_exit_code()`; `UNKNOWN`→4), `scripts/test_watch_agent.py` (8 offline cases), `reference/subagent-supervision.md`, cited in `implementing-features` Step 8; the read-only `opencode.db` access is documented in `reference/opencode-integration.md`. **Follow-up (2026-10-02):** the watchdog is orchestrator-invoked; making the heartbeat automatic is a future skill-level change.
