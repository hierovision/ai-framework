## Detail at extraction

Companion to RM-058 (delivered 2026-10-16: attach-vehicle wake path). RM-058 owns the completion signal; this row owns continuation — a role/session reaching a phase boundary is handed to a fresh session resumed from artifacts (decisions carried), and high-fan-out waves return summary + artifact pointers rather than flooding the orchestrator context (APM's Handoff + Memory pattern; Anthropic's subagent-output-to-filesystem pattern).

Harnesses auto-compact (opencode, Claude Code with per-subagent autoCompactWindow, etc.), so the failure this row addresses is **not** exhaustion but lossy, invisible continuation: the child proceeds on a model-generated summary and can contradict an earlier recorded decision.

**Trigger** (owner decision 2026-10-16): first compaction-divergent dispatch — a child's recorded output after auto-compaction contradicts an earlier recorded decision (reverts a choice, redoes completed work, re-asks a settled question).

Design territory to own: the handoff trigger (phase boundary, or a compacted-context signal), the artifact set a fresh session resumes from, an archive/refresh-trail entry, and the pointer-return contract for dispatch waves (council exempt — full lenses required).
