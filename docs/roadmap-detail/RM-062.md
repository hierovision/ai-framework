## Detail at extraction

Owner decision 2026-10-16: this row is **proactive, not failure-gated**. It ships restart-recovery now; the checkpoint model proper is split to RM-064 (gated to RM-055). Horizon moved Later → Next, re-scored 4 (horizon-move exception).

**What "the ceiling" means in real terms.** The post-RM-058 model is: detached children writing files (heartbeat, stream, result, run log), polled by the watchdog and completion observer; the wake delivered through the orchestrator's live server; abort authority in the session guard. Concretely it does not:

1. **Survive a host/session restart** — a detached child can be orphaned and its wake target disappears (`WAKE_DEFERRED reason=no-attach-target`); files persist but nothing re-drives the run.
2. **Carry a multi-phase sequence** — dispatches are bounded (≈10-min checkpoints, 180 s call cap, 45-min guard budget); there is no persisted phase state machine, only the plan document.
3. **Guarantee exactly-once / replay** — a crash mid-write leaves partial files, and restart has no resume-from-checkpoint; side effects (push, migration) are not transactional.
4. **Guarantee wake delivery** — best-effort with deferral, not a durable outbox.

**Deliverable.** (1) A reconciliation sweep run at session/orchestrator start (or on demand) that scans the existing durable surface (heartbeats, worktrees, run log, session DB) for detached dispatches whose process is gone and whose terminal state was never claimed, classifies them **completed-but-unlanded / interrupted / dead**, and surfaces them for land-or-resume. (2) The stated ceiling paragraph (guarantees and non-guarantees) in `reference/subagent-supervision.md`, plus a small ADR.

**Remaining limits, stated not papered over:** multi-phase sequence resume and exactly-once side effects — RM-064.

**Deferred escalation design** if the ceiling is ever raised: Microsoft Agent Framework checkpointing/time-travel + Durable Task extension (fetched 2026-10-16). No external engine is adopted at solo scale (plan §8 — file-based, zero external services).
