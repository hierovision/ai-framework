## Summary

The framework's foundation tiers are delivered and the lessons of the first
consumer exercises are now contract: observability + behavioral-eval CI with
per-change gating (RM-001–RM-003), the governance structure + registry
(RM-004/RM-005), the two-way exercise loop (RM-014), subagent supervision +
delegated-result contract + session-guard hardening (RM-022/RM-023,
RM-045/RM-047/RM-048), agent-team dispatch + persona cast (RM-032/RM-033),
Go-first model bindings (RM-039), the friction-log remediation (RM-050),
and — merged 2026-10-11 ([PR #110](https://github.com/hierovision/ai-framework/pull/110),
[PR #111](https://github.com/hierovision/ai-framework/pull/111)) — the
RM-021 residue (canary prompt corrections) and the new roadmap contract:
strategy-only vision docs, Now/Next/Later confidence horizons, no ACs in
roadmap items, dependencies first-class (RM-052/RM-053). This file migrates
to that contract in this pass; open-row detail lives one click away in the
§Detail archive, and the reading experience itself is RM-057's design pass
(owner-ruled, Now).

Maturity baseline: Level 2–3 (Defined), trending. Target: Level 4
(Operated / Capable) on speed and quality.

Note: no single standard exists for an "agentic dev lifecycle" — we compose
the reference models below. Authority comes from the backbone; day-to-day
scoring uses the Rex Black rubric.
