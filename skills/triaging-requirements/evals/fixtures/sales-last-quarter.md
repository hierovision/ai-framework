# Sales Requests — Last Quarter

Collected from customer conversations and demo feedback, Q2 2026.

## High-ask

- **Spanish localization** — 3 enterprise OT clinics in Madrid asked. They'll buy 50 seats each if we ship ES. High confidence they convert.
- **Bulk activity import from CSV** — a school district (200 therapists) wants to upload 100+ activities at once instead of hand-entering. They have a spreadsheet ready.
- **Pause-all across running timers** — a therapy practice running group sessions wants one button to pause every active timer. Mentioned by 2 of the top-5 accounts.

## Medium-ask

- **Mandarin localization** — 1 prospective clinic in Shanghai. Lower confidence; they're also evaluating a local competitor.
- **Share activity via link (read-only)** — therapists want to send a parent a link to run an activity at home without installing the app. Novel use case; we're not sure adoption will follow.
- **Custom phase transition sound per activity** — already partially supported (phase-level override exists) but sales keeps getting asked for a "distinct transition cue" separate from completion sound. May be a documentation problem, not a feature.

## Low-ask

- **YouTube URL as completion sound** — 1 user asked on the forum. We have no signal it's broadly wanted.
- **Apple Watch companion** — 1 enthusiastic user. Massive effort, tiny reach.
- **Dark mode scheduled by sunset** — 2 users. Nice but trivial; they already have manual dark mode.
- **Recurring activity schedules (Mon/Wed/Fri auto-start)** — 1 OT clinic. Interesting but a big lift and unclear pull beyond one account.
