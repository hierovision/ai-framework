# forj-notes

Agentic meeting-notes skill for collaboration with teammates and my
notional co-founder. It keeps a per-project notes ledger under
`notes/`, derived from the meeting transcripts the user drags in, and
summarizes with a two-pass rubric (decisions | follow-ups | metrics).
The rubric is the most portable part; the transcript importers assume
Cloudinary-hosted audio which we do not intend to keep.
