# forgetful-mentor

An agent skill for spaced-repetition study coaching. Surfaces cards due
today, adapts intervals from recall performance, and drafts nightly
session plans. Its `review-loop` rubric (weighted recall × recency)
and the TSV card schema (`cards.tsv` with fields `front|back|interval|
ease`) are the strongest parts of the design; the web dashboard is
optional.
