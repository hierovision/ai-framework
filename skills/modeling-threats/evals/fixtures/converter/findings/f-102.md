# Finding f-102 — path traversal in `convert(path)`

- Source: static scanner, 2026-09-02
- Component: `core`, entry point `convert`
- Report: `convert` joins the caller-supplied `path` with the working
  directory without normalizing `..`; a crafted path can read or write
  outside the intended directory.
- Reporter severity: high
- Required attacker position: whoever can choose the `path` argument.
